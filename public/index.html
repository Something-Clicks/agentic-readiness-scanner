Scan

This is the diagnostic API for Something Clicks. It checks whether AI agents can read, find, and act on a local business website.

  • GET /scan?url=… — run a scan. Add &tier=full for the itemized report, &format=text for plain text.
  • GET /health — service status and the user agent scans are sent with.

Every request this service makes identifies itself honestly. It never sends another platform's crawler user agent.
